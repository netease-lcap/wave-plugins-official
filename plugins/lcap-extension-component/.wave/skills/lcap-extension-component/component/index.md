# 组件开发指南

## 1. 初始化组件

使用工具创建组件。


## 2. 开发说明

开发需要完成的内容如下图：

- \[必要配置] [api.ts](./api.md)：组件配置说明， 描述用户组件的配置面板生成，应用翻译等。
- \[必要配置] [block.stories.{js|tsx|jsx}](./block.md)：组件拖转到画布后初始生成的代码示例。
- \[必要配置] [页面编辑器适配](./ide.md)：IDE 页面编辑画布适配，用于在页面上的展示。
- \[可选配置] IDE 功能适配 ：主题配置、国际化能力等扩展能力适配。
- \[可选配置] 平台能力适配 ：对平台提供能力的适配。
