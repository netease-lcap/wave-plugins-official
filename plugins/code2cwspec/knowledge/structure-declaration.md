# 数据结构类型定义

本文档描述生成数据结构类型定义的流程与注意事项，我们使用 NASL（NaturalTS）+ 表格的格式来描述数据结构类型定义，必须严格遵守规则的前提下遵守以下流程生成。

## 关键规则

- 禁止使用 union 类型
- 禁止使用 `import` 引用任何代码模块
- 禁止使用 `a: string | null`，推荐使用 `a?: string`
- 数据结构定义不支持泛型，禁止使用任何泛型
- 枚举属性严格遵循示例中的 特别注意 格式
- 数据结构属性严格遵循示例中的 特别注意 格式
- 每个数据结构属性添加注释，注释包含数据结构属性的中文名称、详细的功能描述，禁止遗漏任何数据结构属性的注释描述
- 必须仔细思考数据结构对应的业务功能，生成实际业务中需要用到的所有业务功能属性，禁止遗漏任何需要的业务功能属性
