## 无权限页（noAuth）

### 功能概述

无权限页是权限中心模块的必备页面，用于在用户访问无权限资源时展示 401 提示。页面采用居中布局，展示 401 标识、提示文案「你没有访问该页面的权限」，以及「重新登录」「返回首页」两个按钮。本页设置 `auth: false`，确保未登录或无权用户也能访问并选择重新登录或返回首页，与登录页、权限中心布局等共同构成完整的权限体验。

### 页面签名

```naturalts path="app.frontendTypes.pc.frontends.pc.views.noAuth.tsx"
$View({
    title: "无权限页",
    auth: false,
    isIndex: false,
})
export declare function noAuth();
```

无输入参数。

### 验收列表

- 当用户访问无权限资源时，应能跳转至无权限页并看到 401 与「你没有访问该页面的权限」提示【服务端逻辑-无】【实体-无】
- 页面必须提供「重新登录」按钮，点击后跳转至登录页【服务端逻辑-无】【实体-无】
- 页面必须提供「返回首页」按钮，点击后跳转至首页（/）【服务端逻辑-无】【实体-无】
- 页面布局应居中、垂直排列，主内容在视口内居中【服务端逻辑-无】【实体-无】
- 本页必须设置 `auth: false`，无需登录即可访问【服务端逻辑-无】【实体-无】
