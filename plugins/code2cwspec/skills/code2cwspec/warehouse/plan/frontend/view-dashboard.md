# 通用业务模块-总览页（dashboard）

## 总览页（dashboard）

### 功能概述

总览页是通用业务模块的顶层路由承载页面，主要用于展示模块内导航菜单，并作为子页面内容的统一容器。用户可通过导航菜单进入当前模块下真实存在的功能页面，而总览页本身不直接承担具体业务表单、数据处理或复杂交互逻辑，只负责提供稳定的页面框架，并通过路由视图加载当前访问的子功能页面。

### 页面签名

```naturalts path="app.frontendTypes.pc.frontends.pc.views.dashboard.tsx"
$View({
    title: "总览页",
    crumb: "总览页",
})
export declare function dashboard();
```

无输入参数。

### 交互操作

- **页面初始化加载**：用户进入总览页后，页面展示基础布局与内容承载区域，并在主内容区域加载当前路由对应的子页面内容。
- **导航菜单承载**：总览页负责展示模块内导航菜单，用户可通过导航菜单进入当前模块下真实存在的子功能页面；导航菜单本身仅承担页面切换入口作用，不在当前页直接处理具体业务逻辑。
- **模块内页面切换承载**：用户通过模块内已有导航切换到其他功能页面时，总览页继续作为统一路由容器承载目标子页面，仅更新内容展示区域，不新增额外业务处理逻辑。

无依赖的服务端逻辑。

无特殊组件。
