# change-ledger

记下**这条会话**改过哪些文件，并把 git 工作区的实时状态放在同一块面板里。

## 用法

- `/changes`：打开「变更」面板，同时把当前状态念一遍给模型听。
- 之后每次 Edit / Write，那条工具调用下面会多一行 `+2 −0 · 本会话第 1 次改这个文件`。
- 输入框下面常驻一行：`改动 2 个文件 +4 −0 · feature/xxx`（不在 git 仓库里就没有分支名）。

## 面板里有什么

| 区块 | 内容 | 数据来源 |
| --- | --- | --- |
| 顶部 | 分支、领先/落后、本会话的合计增删 | `$.session.repo()` + `git status --porcelain=v1 --branch` |
| 本会话改过的文件 | 文件名、增删行数、被改了几次 | `tool.call`（Edit / Write）逐次累计 |
| 工作区 | 每个改动文件的状态与增删行数，`●` 标出本会话动过的 | `git status` + `git diff --numstat HEAD` |
| 子代理 | 这条会话里的子代理 | `$.agent.list()` |

底部两个按钮：**复制清单**（`$.ui.copy`，纯文本、可直接贴进 issue）、**刷新**（重读工作区并重画）。

## 口径与边界

- 增删行数是**去掉首尾相同行**之后的差值，不是 diff 算法的结果；一次大改的中段重排会算成「多删多增」。
- 记录发生在工具**执行之前**（`tool.call` 拿不到执行结果），所以被审批拒掉的编辑也会先记上。
- 面板高度不归插件，所以每类最多画 6 行，多出来的写「还有 N 个没画出来」；完整内容用「复制清单」取。
- 不在 git 仓库里也能用：只有「本会话改过的文件」那一块有内容。
